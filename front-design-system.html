Overview

TL;DR. Front’s Global UI Kit in Figma and the components in production had drifted apart: the same button had different hover colors, toggles used old values and spacing changed from screen to screen. Each fix was too small for an engineering sprint, so they stayed in the backlog. I started fixing them myself: auditing components against the Figma kit, updating the code with Claude Code, documenting every state in Storybook and opening my own pull requests for engineers to review. Result: 40+ UI fixes shipped to production across 12 components.

The problem

Two sources of truth

Thousands of support teams work in Front all day, so small inconsistencies add up: a hover state that doesn’t match, a toggle that looks disabled when it isn’t, a pill with a different radius on every screen. Designers specified components from the Figma kit, but production had copies with hard-coded values. Design reviews kept ending in the same comment, “this doesn’t match Figma”, and nobody owned the fix.

Key decisions

01

Fix the token, not the pixel

Every fix maps to a token in the Global UI Kit instead of a hex value. A primary button uses color-semantic/bg/fill/primary, which points to blurple/600. That way the fix holds in all four theme modes without extra work, and the next change happens in one place.

02

Claude Code as my pair

I describe the component and its Figma spec, Claude Code finds where it lives in the codebase, proposes the change and runs the checks. I review every line of the diff before it goes anywhere. It turned a fix that used to need an engineer’s afternoon into something I could do between design reviews.

03

Storybook is the contract

Every fix updates the component’s stories with all its variants and states. Designers and engineers review the same thing, and the next person who uses the component sees how it should behave instead of copying it from another screen.

04

Small PRs, easy to review

One component per pull request, with the Figma link, the before and after, and the stories that changed. Small PRs got reviewed the same day, and engineers started tagging me on UI questions instead of guessing.

Impact

A designer who can ship small fixes changes the conversation with engineering: we spend review time on behavior, not on hex codes.
